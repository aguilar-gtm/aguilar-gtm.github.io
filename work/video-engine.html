A video production engine that won't deliver a film it hasn't measured.

I built this for client video work: script, voice, picture, music and final cut, on open models running on a single 8 GB GPU at $0 marginal cost. The hard part wasn't generating video. It was knowing, before a client saw it, that the output was right. So every stage has to prove itself in code before the next one starts.

02 · decisionseach one earned by a failure

Every gate is named after the failure that earned it.

  1. Voice takes are re-heard, not trusted.

    A 34-line voiceover shipped with 11 defective takes. The script said 1930, the audio said 1960, and the film's thesis line came out as a different sentence. Every take is now transcribed back and diffed against the script before picture starts.

    the rule already existed in prose; the stage ran without it
  2. Renders are costed from disk before the GPU starts.

    A 43-second cut took about 7 hours, and the deterministic layers took 7 minutes of that. The route gate refuses any plan whose rate came from a smoke test, or that was never compared against a cheaper route.

    generative vs deterministic, same film: 67:1
  3. The machine is measured, not assumed.

    A take predicted at 49 minutes ran 308 because free RAM sat at 0.2 GB and the model paged through disk the whole time. Nothing errored. Commit headroom and free physical RAM are different numbers, so the gate reads both.

    49 min predicted, 308 actual
  4. A runaway job can't take the machine down.

    An unbounded loop reached 59.4 GB of commit and crashed the workstation twice in one evening. Every entry point now runs inside a Win32 job-object memory ceiling, which proves itself in both directions before the job starts.

    a cap that refused everything would pass a one-sided test
  5. The instruments get tested before the output does.

    The sound suite's first full run had 21 failures, and 17 of them were the measuring instruments: a pitch tracker that read 523 Hz as 381, and a note detector that shattered notes. Instruments now run first against signals with a known answer.

    a check and the thing it checks can't share an author
  6. Licences are enforced in code.

    The local voice-clone model is non-commercial. A guard refuses to load it on any billable run, and narration falls back to an Apache-2.0 model. The routes that are cleared for commercial use live in a ledger, not in memory.

    client work can't depend on a licence nobody read
03 · craftbeyond the gates

Some problems were solved by not using AI.

  1. Continuous take, zero cuts, on 8 GB.

    A sub-5-second cut rhythm is the tell of every cheap AI ad. So the engine chains latents into one continuous 15-second take, using a 14B image-to-video model quantized to fit an 8 GB card. That costs about 16 minutes per clip.

  2. A raycaster instead of diffusion.

    For found-footage pieces, diffusion can't hold one frame to the next. A deterministic voxel raycaster can: frame N+1 is the same world re-measured, not re-imagined. Its consecutive-frame delta is 5.97/255, and it matched the reference film's mean luma within 1.1.

  3. A generator, not a file.

    The comedy sound library is 31 seeded generators, so a gag that lands four times plays four different versions, with nothing to license. 325 checks run, including one that the effect survives a phone speaker.
