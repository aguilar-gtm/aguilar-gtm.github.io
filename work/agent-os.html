The operating layer that lets one person run four products through a coding agent.

Everything on this site was built through Claude Code, by someone who started with no coding background. An agent forgets everything between sessions and narrates its own work, so the agent itself was the easy part. The hard part was everything around it: state it can't lose, rules it can't skip, receipts it doesn't write, and engines that run while nobody is watching.

The agent reads a computed brief, works behind a guard, and closes by writing state.

02 · decisionseach one fixes a way agents fail

Prose reminders have a measured failure rate. So everything here is code.

  1. One file holds the truth.

    Live numbers like revenue, focus and deadlines live in one capped state file. A checker fails the session if a copy of any of them shows up anywhere else, because a real revenue figure once sat correctly in that file while every other layer reported zero for weeks.

    no other file may hold a copy of a live number
  2. The brief is computed, not written.

    Each session opens with a brief built from the record. It counts closes that reported delivery but were never billed, flags sentences that repeat across sessions, lists sessions that never closed, and shows each product's development days against a weekly cadence. A sentence the agent wrote about itself counts for nothing.

    the ledger changes when the record does, not when the story does
  3. Mistakes become refusals.

    Once a mistake has cost a real defect three times, it becomes a guard rule that blocks the tool call and gives the fix. That's 15 rules and 498 refusals so far, each rule carrying a test that proves it fires.

    public: claude-code-guardrails
  4. The receipt isn't the agent's.

    A hook written by the harness after each tool call logs every action that changed a file or left the machine. The agent's summary is a claim, and the trace is the receipt. They have different authors.

  5. Engines run while nobody's watching.

    Scheduled jobs run without anyone at the keyboard: a 07:00 prospect and job finder, an hourly gig watch, a daily channel operator, and a nightly vault backup. Each one finds and prepares work, and none of them sends anything. Every send is a human decision.

Withheld: the vault, memory and state files, because they're personal and client data. The guardrails are public. I can show the rest on a screen share.
