An outbound agency where the operator never has to remember a rule.

This is the engine behind the lead-generation agency I run in Lima. It covers the whole path: account lists, the copy, a console for each client, and the public site. It started as a rebuild of outbound systems whose safety rules lived in prose that only their author read. The thesis is that any rule a new SDR would have to read to stay safe gets turned into code, or it doesn't exist.

02 · decisionswhat makes it operator-grade

The defects it was built to make impossible.

  1. A gate that can't check has to fail, never go quiet.

    Outbound systems fail in three silent ways. A safety indicator whose two branches print the same string, so it can only ever report "safe". A bounce rate divided by the wrong denominator, which dilutes a real failure by the number of steps in the sequence. A check whose input disappeared, so it reports "N/A" in green. Every gate now prints what it checked, the value it read and the threshold.

  2. Copy is generated from a filled intake, never from vibes.

    The client onboarding form has 27 fields, 7 of them mandatory. An empty required field fails and names itself, because an empty fact is something the copy will later try to cite. Spintax depth is calibrated against a measured reference sequence (6 to 23 alternatives per sentence block), and emails are capped at 100 words and two questions.

  3. Each client console is generated from disk.

    A client's console isn't hand-built. It's generated from their account list, intake, sprints and receipts, and it shows a "read from disk" badge. Four gates assert that mode, among them zero typed tax IDs, zero typed addresses, and an inbox that refuses to compose when the data isn't there.

  4. The public demo can be played with but not lifted.

    Visitors can use the live console, and copying its code is expensive. At publish time the code is obfuscated and domain-locked, and served with a CSP built from sha256 hashes. Those hashes are computed over line-ending-normalized script text: the first deploy hashed the bytes on disk, and the browser blocked the site's own navigation. A gate compares every screen pixel-for-pixel before and after, against a measured noise baseline.

Withheld: the copywriting step, the console, the site, and every client's data and copy. The list layer is public in outbound-engine. The console is replayed on synthetic accounts on the home page. Walkthrough of the rest on request.

Stack: Python (standard library) · vanilla JS · Cloudflare Pages · javascript-obfuscator · Playwright for visual gates.
